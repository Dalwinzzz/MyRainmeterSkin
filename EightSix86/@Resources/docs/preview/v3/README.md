# EIGHTY-SIX 雨滴主题 · v3 重做设计 — 第一版预览

> 在浏览器打开 `index.html` 即可查看（已内嵌 Google Fonts，需联网加载字体）。
> `render2x.png` 是 2x DPI 静态渲染截图，供离线参考。

## 为什么推翻旧版

旧版（深色 + 红蓝框 + 汉字装饰 + 中文乱码）方向错了。
对照仓库 `@Resources/origin/` 的官方原图（`system_status_1/2.png` = Handler 操纵台花名册，`battle_field.png` = 战场 HUD），**真正的 86 视觉语言是亮蓝白底的军用电子花名册/数据台**，不是赛博朋克黑红。

## 设计系统（已冻结）

| 维度 | 决策 |
| --- | --- |
| 脸 | 瑞士国际主义 × 军用制式 — 高对比、网格森严、排版主导 |
| 字体 | Oxanium（数字/标题）+ Chakra Petch（标签/表格切角工程字）+ 思源黑（中文） |
| 5 色板 | 纸蓝白 `#e8eef4` · 墨蓝近黑 `#0d1b2a` · 钢蓝 `#2f6db0` · 雾蓝灰 `#8aa2bb` · **猩红 `#d4202a`（唯一强调）** |
| 配色应用 | 冷蓝统治画面，猩红只在「死亡/警告/今日/当前」刺出，绝不平分 |
| 背景 | 黄昏铁道蓝紫渐变 + 细坐标网格 + 雨丝噪点，非纯色 |
| signature moment | 花名册行上斜压的猩红 `CRITICAL/DESTROYED` 阵亡标记 + 中央时钟扫描框 |

## 五个组件

1. **硬件状态 = SYSTEM ROSTER 花名册**（左上）— 86 最标志性界面：编号列 + 单元名 + LOAD 进度条 + 数值 + 升降箭头；DISK 满载时触发 `CRITICAL` 斜压猩红标记。
2. **时钟 = CHRONOS**（中央 signature）— 142px Oxanium 大字，猩红冒号，扫描线框托底，下方日期 + 中文星期 + 系统状态条。
3. **日历 = CALENDAR**（右上）— 月历网格，今日猩红切角块，底部年度进度条带猩红进度头。
4. **音乐歌词 = MEDIA / PARA-RAID**（左下）— 切角封面 + 脉冲点 + 三行歌词（当前行猩红 ▸ 高亮）+ 进度 pin + 控件。
5. **Dock = LAUNCH BAY**（底部居中）— 5 个 Spearhead 战队制式徽记（UT/BD/GS/LF/SW + RGL 编号），hover 上移 + 猩红角括号浮现。
