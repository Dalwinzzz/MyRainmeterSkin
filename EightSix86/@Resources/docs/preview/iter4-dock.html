86 HUD Dock v1.1.0 — 兑现 v1 设计承诺的 hover（鼠标悬停每个徽记看反馈）

本轮兑现 v1 设计的 Dock hover

  • 整体上移 3px：MouseOver 时 mark Y 偏移 4→1（launcher 轻浮起）
  • 描边变亮：每个 mark 描边色抽成 #L*Mk# 局部变量，hover 从蓝边 → 纯白（BIN 从暗红 → 亮红）
  • 4 角括号 tick 浮现：#L*Tk# alpha 0→255，悬停时四角浮现锁定框
  • glow 加强：drop-shadow 蓝/红辉光增强
  • 5 个 Spearhead 徽记：UNDERTAKER 送葬人 / BLACK DOG 黑犬 / LAUGHING FOX 笑狐 / GUN SNAKE 银蛇 / SNOW WITCH 雪魔女（红）
说明：此 HTML 仅作风格/逻辑预览，不是皮肤本体。真实皮肤是 Dock/Dock.ini： 每个 mark 描边色 #L*Mk#、Y 偏移 #L*Ty#、tick alpha #L*Tk# 三个局部变量；MouseOver/LeaveAction 用 !SetVariable + !UpdateMeterGroup 切换。SVG 个人 mark 由 Shape meter 多 path 组合绘制（v1 占位， 后续可换精修 PNG）。已 Python 校验 5 mark 全变量化、各有 tick、组成员正确。Windows 端待确认： hover 上移手感、描边变白的对比度。
