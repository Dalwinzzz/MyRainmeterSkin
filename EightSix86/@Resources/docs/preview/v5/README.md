## 针对 v4 的两条反馈

### 反馈① 「没跳脱出之前版本的束缚」→ 换布局骨架

v1–v4 一直是同一套 **四角对称堆面板**（左上花名册 / 右上日历 / 左下音乐 / 中央时钟 / 底部 dock）——
这是最 AI 默认、最「均匀平庸」的布局。v5 彻底换骨架（用户拍板「左侧指挥栏 + 主视觉留白」）：

- **左侧一条竖直「指挥控制栏 COMMAND RAIL」**：86 标识 + 花名册 + 音乐歌词 + 日历，全部数据组件归到左侧一条，**用分隔线划分而非独立卡片** → 整体作战系统感，不是零散小卡片。
- **屏幕主体大面积留白**，只放中央偏右的**纯白时钟主视觉** + 底部 dock。
- 打破对称、信息归一侧、强呼吸感 —— 这是「跳出束缚」的核心。

### 反馈② Dock 要 Undertaker 骷髅骑士那种「个人纹章 logo」

不再是抽象机甲剪影。改为 **5 个 Spearhead 成员的个人纹章**（SVG 手绘线稿徽记风，参考你给的
Undertaker 无头骑士骷髅 Dullahan 黑白线稿）：

| 纹章 | 成员 | 视觉 |
| --- | --- | --- |
| UNDERTAKER | Shin | 颅骨 + 高举的剑 + 斗篷黑块 + 镰刃横扫弧 |
| BLACK DOG | Raiden | 獠牙犬首 |
| GUN SNAKE | Theo | 蛇缠枪管 + 狙击准星 |
| LAUGHING FOX | Kurena | 尖耳狐面 + 上挑笑眼 |
| SNOW WITCH | Anju | 六芒雪结晶 |

- 每个纹章 = 圆环（实线 + 内虚线）+ 线稿徽记
- 默认银白线，**hover：上移 + 整体点亮猩红 + 红色辉光环**

## 设计系统（沿用 v4，透明叠暗壁纸）

- 字体 Oxanium + Chakra Petch + 思源黑
- 5 色板：冰蓝白 `#dbe9fb` · 钢蓝 `#6fa8e0` · 深钢蓝 `#3f6fa0` · 雾蓝灰 `#8da6c4` · 猩红 `#ff3b3b`
- 冷蓝银白统治，猩红只在 CRITICAL/今日/当前歌词/hover 刺出
- 指挥栏透明度可调（`--glass-opacity`，顶部滑块）
- signature moment：花名册斜压猩红 `CRITICAL`

## 五个组件（全在左侧指挥栏 + 中央/底部）

1. 硬件状态花名册（栏内顶部，含 CRITICAL）
2. 时钟 CHRONOS（中央留白区主视觉，纯白）
3. 日历（栏内底部）
4. 音乐歌词（栏内中部）
5. Dock 成员纹章（底部居中）
