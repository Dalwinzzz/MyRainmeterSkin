## 设计系统 v4（透明叠暗壁纸版）

- **脸**：瑞士国际主义 × 军用制式
- **字体**：Oxanium(数字/标题) + Chakra Petch(标签/表格) + 思源黑(中文)
- **5 色板**：冰蓝白 `#dbe9fb` · 钢蓝 `#6fa8e0` · 深钢蓝 `#3f6fa0` · 雾蓝灰 `#8da6c4` · **猩红 `#ff3b3b`**（+ 极少量徽章金 `#e8b94a`）
- **配色逻辑**：冷蓝钢蓝 + 银白统治，猩红只在 CRITICAL/今日/当前歌词刺出，绝不平分
- **背景**：暗色二次元壁纸（蓝紫渐变 + 远处银白人物光晕 + 坐标网格 + 雨丝）
- **signature moment**：花名册斜压猩红 `CRITICAL`

## 五个组件

1. **硬件状态 = SYSTEM ROSTER 花名册**（左上）— 86 标志界面，DISK 满载触发 CRITICAL 斜压
2. **时钟 = CHRONOS**（中央 signature）— 146px 纯白大字 + 扫描框
3. **日历 = CALENDAR**（右上）— 月历 + 今日猩红切角 + 年度进度
4. **音乐歌词 = MEDIA / PARA-RAID**（左下）— 封面 + 三行歌词当前行高亮 + 进度
5. **Dock = LAUNCH BAY**（底部）— 5 架机体机徽，hover 上移 + 猩红点亮
